# Security reports

Do not post working harmful payloads, model responses, credentials, or private result
records in a public issue. Use the repository's
[private security-advisory channel](https://github.com/Lman7154/smuggle/security/advisories/new)
or contact the project author and supervisor through the University of Pretoria.

This repository is a research measurement artefact, not a production guardrail. A
classifier result produced by the code must not be treated as a security guarantee.
