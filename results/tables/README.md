# Generated report tables

All files in this directory are generated by:

```bash
python scripts/make_report_tables.py
```

The CSV and JSON files are the machine-readable results, including both
pre-probe-conditioned descriptive strata, the adaptive protocol/truncation audit, and
conservative sensitivities. Variant-delivery rates are descriptive and the report does
not attach confidence intervals to them because Goals contribute repeated variants.
The `.tex` files are consumed directly by `report_final/report.tex`; do not edit their
numbers manually. Regenerate them after changing the public derived data or
statistical implementation.
